**STM32F401RE Peripheral Driver Porting and Application Analysis**

**Project Overview**

This repository contains the ported bare-metal peripheral drivers and application examples for the STM32F401RE microcontroller. The project involves analyzing existing reference drivers, porting them to the target board, and implementing specific application codes.

**Repository Structure**

- STM32F446RE_Drivers/: Contains the core peripheral drivers.

- examples/New Examples/: Contains the newly implemented application codes for STM32F401RE.

**Implemented Examples**

- GPIO Configuration & LED Toggling

- USART Communication

- I2C Sensor Interfacing

- SPI Communication

**Board Details**

- Target Microcontroller: STM32F401RE
